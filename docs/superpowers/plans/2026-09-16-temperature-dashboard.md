# M1 温度看板实施计划

用户已明确授权本次实现；复用现有只读 API，不动采集器、OPC UA 实验和用户数据。

## 方案

frontend 使用 React / TypeScript / Vite / ECharts，npm 精确依赖和锁文件。
- 一页中文：设备名/协议、最后温度/单位/原采样时间、最近尝试结果/时间、后端数据年龄/过期状态、最后前端获取成功时间、10分钟曲线。
- 通过设备列表选择motor-a；每轮串行 devices→latest→history，整轮成功才更新快照。历史时间范围以latest.checked_at为终点，limit1000，升序；达到上限明确可能截断。
- 轮次完成2秒后启动下一轮，8秒请求轮次超时；卸载取消请求/定时器，过期响应不写状态。延迟刷新超过6秒显示待核实，不把旧状态当当前状态。
- API失败保留最后值/时间/图表，明确未核实；不推断在线/健康。无样本显示空数据而非0。
- 真实time轴，默认1秒采集下相邻记录超过1.5秒插入null断线标记（非样本），不插值，不跨缺口连线；固定温度Y轴至少留±1℃，空/单点可见，图表提供文字摘要。
- Vite /api代理默认127.0.0.1:8000，可环境变量配置，无需CORS修改。桌面和390px窄屏适配。

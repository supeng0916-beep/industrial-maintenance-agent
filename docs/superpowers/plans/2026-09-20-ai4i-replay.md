# D13：AI4I 2020 真实数据集回放（扩展工作包）

日期：2026-09-20
定位：把 UCI AI4I 2020 预测性维护数据集（合成、CC BY 4.0、10000 行）以"历史回放"形态接入现有只读管道，让曲线、故障史与助手证据来自真实公开数据集，而非静态仿真值。动机：用户希望项目模仿真实企业问题（企业里最常见的接入形态恰是历史数据回放/批次导入），而不只是协议演示。

## 边界与诚实性合同（不可违反）

- 数据集是**合成数据**（Matzka 2020，模拟数控机床）。页面、API、助手答案的任何展示必须带"历史回放 / 合成数据"标注，不得表述为现场实测。
- `collected_at` 为**回放时刻墙钟**，不伪造原始采集时间；行序保持数据集原序；不做插值、不补点。
- 故障事件直接采用数据集自身的标注列（Machine failure / TWF / HDF / PWF / OSF / RNF），本系统**不再判定**、不改写。
- 数据集 CSV 固定 SHA256 指纹（`dc6630cd…a8e`），启动时校验，不匹配即拒绝回放。
- 复用现有诚实框架：quality='good' 仅表示记录有效；数据过期=回放器停止后的自然表现，前端照常显示"已过期"。

## 字段映射（全部精确转换或原值）

| 数据集列 | 指标 | 单位 | 转换 |
|---|---|---|---|
| Process temperature [K] | temperature | ℃ | K−273.15（精确） |
| Air temperature [K] | air_temperature | ℃ | K−273.15（精确） |
| Rotational speed [rpm] | speed | rpm | 原值 |
| Torque [Nm] | torque | Nm | 原值 |
| Tool wear [min] | tool_wear | min | 原值 |
| Machine failure | running_state | 枚举 | 1=正常运转，0=数据集标注故障（1:1） |
| TWF/HDF/PWF/OSF/RNF | collection_events(event_type='replay_dataset_fault') | — | 原标注写入事件消息 |

不做扭矩→电流之类的换算（无依据，违反诚实纪律）。

## 验收标准

1. `uv run --locked python -m pytest`（原 292 项 + 新增）全部通过；前端 `npm run check` + vitest + build 全过。
2. 回放运行时：motor-c 六指标曲线有真实波动（非水平线）；第 50 行起数据集标注故障在故障史面板出现，标注为"数据集标注"。
3. 页面可见"历史数据集回放（合成数据）· 非实时"字样；API `/api/devices` 含 motor-c 且助手 get_device_status 可查其指标。
4. 回放停止后 motor-c 显示"数据已过期"，不冒充在线；motor-a/b 行为与改动前完全一致（回归）。
5. 仓库不含 zip；数据集 README 含 CC BY 4.0 署名与 SHA256。

## 不做的事

- 不改 alarms.py 阈值机制（motor-c 告警显示"未启用"，故障史来自数据集标注）。
- 不做回放倍速/暂停恢复/多数据集（--interval 已够演示）。
- 不把 CSV 转喂 Modbus/OPC UA 寄存器（直写 SQLite 与 opcua_storage 先例一致，协议仿真由 motor-a/b 继续代表）。

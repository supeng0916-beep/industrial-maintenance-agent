# 面向真实资料的 RAG 来源筛选

核查日期：2026-09-18。用户要求：不能仅依赖少量自编内容；从 Hugging Face、原厂、研究机构等来源寻找有真实场景参考价值的资料。

状态：完成候选发布页和数据卡初筛，未批量下载/导入，未建立向量索引。本文件不作为检索语料。现有5份20块继续用于本项目规则回归，不代表真实维护检索能力。

## 候选来源及取舍

### 1. 原厂电机资料：优先形成主语料

ABB 中文《低压电机安装、操作、维护和安全手册》，检索到文档编号3GZF500730-85、Rev H、05-2022。

- 原始地址：https://library.e.abb.com/public/74e819e620cf4bdc9beb1959e4340b08/3GZF500730-85%20Rev%20H%20ML_05%20CHS_.pdf
- 厂家入口：https://www.abb.com/global/en/areas/motion/motors-generators/low-voltage-motors/iec-low-voltage-motors
- 用途：真实中文技术表达、章节和适用范围；后续核对原PDF页码、有效性章节、相关系列及使用条款。本次搜索可见标题/版本，但PDF直接读取失败，尚未完成文件级核查。
- 不声称这是最新版本；不据此把motor-a/b认作ABB产品。公开下载不是开放再分发授权，许可未确认前不将整份第三方手册发布到项目仓库。

### 2. Hugging Face Industrial-Instruction：重点抽样候选

- 数据卡：https://huggingface.co/datasets/Parssky/industrial-instruction-dataset/blob/main/README.md
- 作者论文说明：https://huggingface.co/papers/2608.22817
- 作者报告来源为906份松下技术文档、7525页；提供PDF提取的Markdown语料与模型生成的QA，两者性质不同。卡片许可为other，要求遵守源文档条款。
- 数据卡示例含电流检测电阻，不能把“industrial”标签等同于电机维护。下一步只抽样核查电机/驱动相关性、原始文档链接、版本、提取质量、许可；合格部分再考虑纳入。
- 正文可候选入库，测试问题与答案必须隔离。真实文档衍生的合成QA不等于真实维修工单或真实用户提问。不同QA配置数量不同，不把多配置总数当独立文档数。

### 3. Hugging Face Industrial Maintenance Synthetic：不作真实证据主库

- https://huggingface.co/datasets/Jvachier/industrial-maintenance-synthetic
- 发布者说明约200万记录，由模板流水线生成，含传感器标签与维修工单，且设置数据杂质。数量大但属于合成资料。
- 可选用途：以后做导入压力/数据质量实验；不作为本项目真实故障原因、维护标准或真实场景评测依据。不下载它来凑语料规模。

### 4. Hugging Face QTE industrial-technical-archive：降级备选

- https://huggingface.co/datasets/QTE-Technologies/industrial-technical-archive
- 页面显示约71683行，内容含产品目录、技术介绍及营销信息；卡片另称整合百万记录，两者口径不能混用。英文/越南文，卡片标CC BY 4.0。
- 需逐条确认原出处和内容深度；目录规模不等于维护知识规模。不优先整库导入。

### 5. TechManualQA-700：方法与外部评测参考

- https://zenodo.org/records/17410809
- 发布者说明700道基于20份技术手册生成并验证的题，含事实、步骤、无答案类，涵盖家电、汽车、电动工具。档案说明许可CC BY 4.0。
- 可借鉴评测设计；领域不全匹配，暂不替代电机专用题集。问答授权不能自动推定所有原手册授权；原资料仍需另行核查。不能把标准答案入库后再测同一道题。

### 6. 美国能源部电机系统资料：通用知识候选

- https://www.energy.gov/cmei/ito/motor-systems
- https://betterbuildingssolutioncenter.energy.gov/better-plants/motors
- 官方入口提供电机/驱动系统运行、性能和管理参考资料。作为英文通用知识补充，不等同特定型号原厂维修手册。后续核对具体文件、版次、页码和权利说明。

### 7. UCI MetroPT-3：真实数值数据独立实验

- https://archive.ics.uci.edu/dataset/791/metropt+3+dataset
- 原发布页说明为列车压缩机APU现场数据，约151万条，含压力、电流、油温和故障报告信息，CC BY 4.0。
- 数值数据应进入独立离线分析/回放流程，不把每行向量化，也不混进motor-a/b真实身份。说明及报告可作为该数据集背景资料。
- 发布页同时出现1Hz与0.1Hz描述，后续导入须检查实际时间戳间隔，不直接假定采样频率。

### 8. UCI AI4I 2020：明确为合成数据

- https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
- 原发布页明确为合成预测性维护数据，约1万条，CC BY 4.0。适合算法教学，但不能冒充现场实测；Kaggle镜像不改变其性质。

## 调整后的落地顺序

1. 核查并取得真实文档：先以电机/驱动维护为主题，目标选10～20份有足够实质内容的原始文档或独立指南，尽量有2～3个来源/系列。这个数量是初期规模目标，不是已取得数量；不通过重复文档/翻译副本凑数。
2. 建来源登记：原始URL、发布者、标题、编号、版次、语言、适用系列、获取日期、文件哈希、使用条件及是否允许再分发。先保留原文，AI整理/翻译另标衍生内容及对应页码。
3. PDF/Markdown解析：抽查表格列头、跨页条件、单位、型号和警示是否丢失。当前整章超过512即报错的预览策略，需要在真实资料上验证并补充段落/表格分组策略，不能假装现有实现已经覆盖长手册。
4. 模型试验：原定bge-small-zh-v1.5仅作为中文基线。若采纳英文或中英混合正文，应以同一批问题比较适合语料语言的嵌入方案；新模型必须重新向量化，不因都512维而混用。
5. 建立真实语料索引并统计去重后的文档数、页数、有效片段数、语言和主题分布；不以随意硬切获得大量块证明规模。
6. 评测扩为约40～60题，覆盖直接事实、口语改写、型号/版本冲突、表格条件、多片段、无答案。开发题与保留题分开，按文档来源分组以避免同段改写泄漏。AI可辅助起题，但答案逐条核原文。
7. 先测向量基线，再按失败样例增加BM25/重排。报告Hit@K、前提完整性、引用支持情况、型号误用、证据不足处理及耗时；不要只报告总体准确率。

原20块是实现验证夹具，不作为真实场景检索效果的主要结论。尚无真实语料索引成绩，也未宣称当前来源全部完成许可和文件核查。

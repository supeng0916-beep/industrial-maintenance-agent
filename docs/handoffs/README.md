## 开始前检查

- 确认工作目录和文件可读；本项目当前不是Git仓库，不为满足流程强制初始化。
- 检查实际在运行的服务，历史端口只是线索；不停止用户原采集进程。
- 读取既有验收而不是接手即重复196项测试；本轮修改后按影响范围验证。
- 生成模型运行方式/预算尚未确定；这一选择才需要向用户提问，不重复询问普通可逆开发许可。

## 后续每个工作包的交付格式

```text
工作包ID/状态：未开始、进行中、通过、受阻
改了什么：文件和用户可见行为
验证：实际命令、结果、证据路径
限制：哪些未实现/未测试，下一步如何验证
学习：本次用户理解了什么、还有哪个具体缺口
下一步：仅一个最小动作
```

详细计划中的新模块/接口都是接下来要实现的设计，不能当作当前已有能力。

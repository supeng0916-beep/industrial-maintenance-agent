# 真实资料检索评测 v0.1

题集文件：real-rag-v0.1.json。创建日期：2026-09-18，先于检索结果标注。

## 语料与范围

15份DOE官方Motor Systems Tip Sheets、30物理页，英文原文；问题为中文改写。数值与建议仅代表所引用历史版本，不作为现行法规或motor-a/b厂家说明。题目与答案不入检索库。

共44题：34道有资料题（每文档2题，另加4道表格条件题），10道相对于当前静态语料/用户给定条件证据不足题。按文档分组：ts02、06、08、12、13的10道有资料题为holdout，其他24道为dev；无答案题各5道。没有用同一段落改写后分到两个集合。

这是小规模内部检查，不是独立第三方基准；holdout仅表示未用于实现调试的问题组，其源文档仍在检索库。结果查看后该集合已被观察，不能在针对其优化后继续声称未见测试集。

## 命中口径

对有资料题，必须匹配预先指定document_id、物理页码及anchors证据片段。仅命中文档另一段不算严格命中。比较original_text和来自原文的context_text，忽略大小写和重复空白，Unicode做NFKC归一化；不能用模型生成的答案去填充证据。

Hit@5/Hit@10分母分别为相应集合的有资料题数。保存全部实际候选及距离，不把余弦相似度当正确概率。expected_evidence为预标注目标，并非穷尽全部等价证据，自动未命中须人工看是否有其他有效出处。

required_evidence/forbidden_claims供人工核对前提、适用性和引用支持，不是本轮LLM回答评分。source_page使用字符串1/2，区别于零基PDF索引。

无资料题只保存候选并人工检查不适用性；当前尚无回答模型和可靠拒答判断，不能报告“自动拒答准确率”。实时状态/历史温度应走SQL工具，而不是期待文档提供。

## 本轮不证明的能力

- 单机构英文指南不证明真实厂家多型号适用性或跨版本冲突处理已经通过。
- 30页不是生产规模，也不是现场传感器/维修工单数据。
- 题集不包括未入库的ABB手册标准答案，不以自编E104解释冒充厂家事实。
- 未运行LLM，不能把检索命中率写成最终回答正确率。

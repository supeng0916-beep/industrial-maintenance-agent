## 新术语（名称 / 通俗解释 / 项目例子）

- **单变量对照实验**：一次只改一个因素，其他全部冻结，变化才能归因。今天唯一变量是"查询语言"；索引、模型、切块、计分、top_k全部不动。
- **基线复现**：跑新实验前先确认"不改任何东西时结果与历史一致"，排除环境漂移。今天24道原查询的top10与冻结评测文件逐题一致，之后英文列的成绩才有可比性。
- **退步题（regression）**：改动后原来对的题变错。R02中文排第5、英文跌出前10——改写用 "power range"，原文写 "between 10 and 500 hp"，意思等价但词汇贴近度下降。
- **门槛（gate）**：事先约定的"是否继续"标准，防止事后挑好看的数字。D1门槛=@5>15/24且@10≥19/24；通过≠生产可用，只代表值得进入D2。
- **检查集 vs 盲测集**：出题者若看过检索结果就不是盲测，只能叫检查集。今天的改写者（我）读过失败记录，所以成绩只能当诊断，不能当独立测试。

## 关键代码或伪代码（标明来自哪个实际文件）

统一计分（`experiments/rag_query_language.py`，直接复用既有计分器，避免两套口径）：

```python
entry['first_anchor_rank'] = next((c['rank'] for c in candidates
                                   if score_evidence(case, [c])[0]), None)
for k in (5, 10):
    entry[f'hit_at_{k}'] = any(score_evidence(case, candidates[:k]))
```

分母保护（同文件 `summarize`）——证据不足题命中为null，永远不进正例分母：

```python
answerable = [r for r in records if r['answerable']]
summary[f'{label}_hit_at_{k}'] = sum(1 for r in answerable if r[label][f'hit_at_{k}'])
```

冻结绑定（同文件 `bind_rewrites`）——题集字节变了或改写动了原题，实验直接拒绝运行：

```python
if _sha256(cases_path) != rewrite_data['source_cases_sha256']:
    raise ValueError('frozen source_cases_sha256 does not match ...')
if item['original_query'] != case['question']:
    raise ValueError(f'original_query drift for {item["case_id"]}')
```

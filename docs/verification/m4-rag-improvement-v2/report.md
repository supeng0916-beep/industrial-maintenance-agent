# D2 评估：默认配置三套题集对照 + 零模型合并候选诊断（rag-check-set-v2）

日期：2026-09-18。执行者：开发线接手Agent。本包**不改动默认检索配置**：无改写、无重排、无新索引。做三件事：①在未变的默认配置（E5最终索引、原始单查询）下重跑旧开发集与旧已观察保留集，复现既有成绩；②首次运行新增的独立检查集 `real-rag-v0.2.json`；③用D1已冻结的top10记录做RRF合并候选诊断（不发起任何新的模型调用、不部署），为D4"查询翻译值不值得做"提供数据。

## D2配置决定

**保持原始E5中文单查询为默认。** 理由：D1证明"等义英文改写"方向有效（@5 20/24、@10 23/24），但可部署的英文查询来源必须是自动翻译，这依赖D4生成模型运行方式决策（供应商/本地或API/预算未定，尚未确认任何密钥）；用手写映射只覆盖评测题是计划明令禁止的部署方式。因此在D4完成前，检索默认配置没有可诚实部署的改动。双语双查询并检的合并机制本身只依赖确定性代码，已按下文诊断口径完成评估。

## 新检查集（real-rag-v0.2.json）

20题：**14道有答案 + 6道证据不足**，全部为从未用于任何调优决定的新题（split=holdout，仅作检查集）。出题者（本Agent）读语料后出题并把锚点核对到索引chunk原文（14/14核验通过后才冻结），**这是新检查集，不是盲测**；每题source_review已注明。覆盖计划要求的四类：

- **表格条件**：C01（NEMA代码G表）、C02（堵转电流502A示例）、C03（涡流50%转速效率区间）、C04（90%电压转矩-19%表）、C05（效率+1%节电2,455kWh表）、C06（MCC压降30,240kWh/$2,750表）
- **相近概念**：C07（对中≠提效）、C08（L10 vs 平均寿命5倍）、C09（+10°C寿命减半）、C10（同步转速=7200/极数）
- **型号/体系不匹配**：C11（IEC电机不能用NEMA代码表）
- **版本/事实**：C12（15英尺反射波）、C13（载波>5kHz轴承损伤）、C14（EISA 2010年12月生效）
- **证据不足6题**：CN01/CN02（当前值/历史值应查业务工具）、CN03/CN04（WEG W22、ABB ACS550无厂家手册）、CN05（IE5限值不在2012语料）、CN06（停机操作只读助手不可执行）

### 新检查集失败题（Hit@5未过）

- **C07**（对中≠提效，ts04第1页）：目标块**未进top10**——唯一完全落空。中文问句"能直接提高效率吗"与原文"no measurable effect on motor efficiency"语义通道弱，与D1的R02同族（候选不在top10，重排/融合无法挽救）。
- **C03**（涡流50%转速效率区间，ts12）：目标块第10名；top3全是ts11（同为调速器效率表，语义近邻竞争）。

## 零模型合并候选诊断（RRF，k=60；不部署）

把D1冻结的每题双查询top10用倒数排名融合去重后重新计分。**复现守卫**：融合前重计D1原查询=15/24、19/24，改写=20/24、23/24，与D1完全一致（`reproduction_status=reproduced`）。

| 方案（诊断口径） | Hit@5 | Hit@10 |
| --- | ---: | ---: |
| 原中文单查询（基线） | 15/24 | 19/24 |
| 纯英文改写单查询 | **20/24** | **23/24** |
| 双查询RRF合并 | 18/24 | 22/24 |

结论：**朴素RRF融合劣于纯英文改写**（18<20、22<23），虽然优于基线。逐题看：合并救回R02（改写版完全丢题→合并第7名），但把R17/R21挤出@10（并列第14）、把R29/R30挤出@5。含义给D4：若引入查询翻译，应考虑"置信回退的翻译单查询"而非两路硬融合；翻译质量本身会引入D1披露过的同类风险。此诊断为非盲、小样本，只用于方向取舍。

## 范围决定（D2第5步）

检索在基线水平（旧集@5=62.5%，新检查集@5=71.4%）。按计划：**文档问答保持实验性**，继续D3受限接线（候选只作为待核查证据返回，附limitations，距离不作为置信度），**不得把可靠文档问答验收标通过**；文档外的数值类问题继续走三个只读业务工具。该取舍已记录，供用户知情。

## 限制

1. 新检查集非盲；出题者即执行者，未用独立出题人。仅确认锚点存在于语料并避开旧题考点。
2. 命中是文档/页/anchor匹配，不是回答正确率；距离不是置信度；anchor不穷尽等价证据。
3. 合并诊断融合的是D1非盲改写的top10，继承其偏差；RRF参数k=60为标准值未调参。
4. 未改变任何默认配置；本报告不构成把检索验收标通过的依据。

# 真实资料 RAG：本地索引与检索基线

本轮实现文档检索层：真实文档切块、实际模型嵌入、Chroma 持久化、查询与离线证据匹配。没有 LLM、回答生成、自动确诊、自动无答案阈值或助手界面。最终索引与成绩在本说明末尾登记；带 preliminary、smoke、v1、v3 的产物为开发检查历史，不作为最终成绩。

## 语料与评测隔离

来源整理任务提供15份 DOE Motor Systems Tip Sheets，共30物理页，保留英文原文、原PDF、来源与文件hash。语料入口只有 `docs/knowledge-real/manifest.json`；不递归导入目录，不展开sources链接，不读取评测问题或答案作为正文。外部文档 `device_ids=[]`、`product_model=null`，不视为适用于所有设备。

冻结manifest SHA256：`2a1da80dca7f618e0b39c19ed77417bc4dc45f1f5655083d10bdbef9b02e15a3`。来源抽查/权利与提取限制由 `docs/verification/m4-real-corpus/` 和源库说明登记。它们是历史通用指南，不自动成为当前法规或特定设备厂家维修指令；本轮只有一个来源系列，不声称覆盖多厂家维护场景。

题集 `docs/evaluation/real-rag-v0.1.json`：44题，34有答案（24dev、10holdout）、10证据不足（各5）。同一语料与冻结题集比较两个模型；不同tokenizer产生不同分块，因此这是两套完整检索配置的对比，不能把差异全部归因于模型权重。

## 构建与查询

在项目根目录运行。输出必须是新目录；例子使用 `rerun-*`，再次执行需更换名字。

```sh
uv sync --locked
.venv/bin/python -m assistant.rag build --manifest docs/knowledge-real/manifest.json --index docs/verification/m4-real-rag/rerun-e5 --model e5 --download-model
.venv/bin/python -m assistant.rag build --manifest docs/knowledge-real/manifest.json --index docs/verification/m4-real-rag/rerun-bge --model bge --download-model
.venv/bin/python -m assistant.rag query --index docs/verification/m4-real-rag/rerun-e5 --query '哪些情形适合评估高效率电机？' --top-k 5
.venv/bin/python -m assistant.rag query --index docs/verification/m4-real-rag/rerun-e5 --query '20马力驱动器的部分负载效率是多少？' --top-k 5 --filters '{"document_id":"doe-motor-ts11"}'
.venv/bin/python -m assistant.rag evaluate --index docs/verification/m4-real-rag/rerun-e5 --cases docs/evaluation/real-rag-v0.1.json --output docs/verification/m4-real-rag/rerun-e5-evaluation.json
```

首次下载后可去掉 `--download-model`；默认离线使用项目 `.cache/rag-models`。模型下载许可来自本轮用户授权，旧的仅tokenizer预览命令仍独立可用。

索引配置保存模型/revision/池化/前缀/归一化/维度/库版本、语料hash、策略、片段hash、持久化文件清单。查询默认从索引配置选择模型，实际加载签名必须完全一致；可显式 `--model` 验证不匹配拒绝。库缺失、空库、损坏配置、缺失HNSW文件均报错，不以自动修复或空候选掩盖。

Chroma `PersistentClient` 显式 `configuration={"hnsw":{"space":"cosine"}}`，其余HNSW参数默认。按 [Chroma官方配置说明](https://docs.trychroma.com/docs/collections/configure)，cosine距离为1减余弦相似度，越小越近，不是置信度或有答案概率。嵌入函数传None，向量显式提供，不让Chroma自动下载其他模型。

构建先计算完整嵌入，再独占创建新目录，重新打开持久化库验证后最后写index.json作为成功标记；异常仅清理本次目录，已有索引拒绝覆盖。语料更新/删除用完整新目录重建，没有对旧库增量追加；因此删除文档不会遗留旧块。被强制杀死可能留下无成功标记的目录，需另选新目录重建。

## 切块与来源

逐物理页、标题、段落/完整句子处理，标题、明确适用范围和表格条件保留为可追溯的重复上下文；普通if/only条件不推断成整页或全篇适用范围。页边界不继承推断的局部条件。

长列表项按完整句子、真正数值表按完整行组处理，重复原始列头/脚注；文本callout保留原始标题与必要前句。无法安全识别或完整输入仍超512时拒绝，不进行字符硬切或truncation。

`original_text`来自真实连续字符区间，所有正文字符覆盖；`context_text`是重复上下文，`context_sources`逐项记录页码/来源，结构拆分重复段还记录字符范围。`source_pages`只标正文物理页，不把整份文档的页码列表灌入每块。完整embedding_text含模型前缀和特殊tokens，实际计数核对。300在本版仅为诊断软标记，实际按512上限贪心装块，未宣称已优化为300-token平均长度或实现固定40-token重叠。

正文覆盖率不能证明语义完整。复杂隐式/跨页前提仍需要多片段与原始PDF核查，例如TS12第二页表2/3与前页50hp示例的关系；候选是供核查的证据，不能把某行数值直接推广为通用规则。本基线不包含通用复杂PDF语义解析器。

## 评测口径

保存真实top10与top5候选，不删除难题。`expected_evidence`按文档ID、物理页、原文anchor核对，统一NFKC、casefold及空白。页码匹配分别检查正文和逐项context_sources，避免将跨页重复条件误算为当前页证据。Hit@K表示至少一个标注证据出现；全部标注证据是否出现另列。没有anchor的旧格式才使用document+section规则。

证据不足题只保存候选，命中字段为null，人工相关性未审就标not_reviewed；有topK不等于有答案。anchor标注也不穷尽全部等价证据，未命中anchor不等于完全没有相关语义；anchor存在仍不等于前提齐全、适用性正确或回答正确，本轮没有自动回答准确率。dev与holdout分开报告；首次比较后本批holdout已被观察，后续调优应增加新的保留题。

## 验证方式

单元测试中的小人工向量只用于索引控制流、距离与过滤验证，不作为模型/真实语料成绩。模型验收和正式构建均使用真实权重，测试池化与官方公式一致、L2范数、512/513边界、批次一致性及语义排序。临时Chroma测试覆盖重启持久化、签名不符、文件缺失、完整新库删除旧文档、参数/过滤、失败不覆盖。

```sh
RUN_REAL_EMBEDDINGS=1 .venv/bin/python -m unittest discover -s tests -v
uv lock --check --offline
```

## 最终交付与成绩（v4）

最终策略为 `rag-page-heading-sentence-v4`。使用以下两份索引，其它预构建仅作历史记录：

- E5：`docs/verification/m4-real-rag/doe-e5-final/`，配置见[index.json](doe-e5-final/index.json)，原文/上下文/来源见[chunks.json](doe-e5-final/chunks.json)。
- BGE：`docs/verification/m4-real-rag/doe-bge-final/`，配置见[index.json](doe-bge-final/index.json)，片段见[chunks.json](doe-bge-final/chunks.json)。

| 配置 | 文档/物理页 | 块数 | token最小/平均/最大 | >300块数 | 嵌入与持久化耗时 |
| --- | --- | ---: | --- | ---: | ---: |
| E5 | 15 / 30 | 113 | 86 / 285.38 / 512 | 45 | 6.091秒 |
| BGE | 15 / 30 | 131 | 93 / 322.76 / 508 | 68 | 2.871秒 |

耗时来自本机单次运行的build_seconds，包含嵌入及索引写入/重开校验，不含模型加载与分块；不是专用性能基准。全部正文字符切片/覆盖校验通过，两个索引的34题标注证据均实际存在。

| 模型 | 集合 | Hit@5 | Hit@10 |
| --- | --- | --- | --- |
| E5 | dev（24有答案） | 15/24，62.5% | 19/24，79.2% |
| E5 | holdout（10有答案） | 3/10，30% | 5/10，50% |
| BGE | dev（24有答案） | 4/24，16.7% | 7/24，29.2% |
| BGE | holdout（10有答案） | 2/10，20% | 3/10，30% |

10道证据不足题全部保留真实候选，命中指标为null、人工相关性not_reviewed，不报告自动拒答成绩。E5本次优于中文BGE，仍未达到可靠自动回答的程度；它只是后续默认候选，不是生产可用结论。

完整结果：[E5评测](e5-evaluation.json)、[BGE评测](bge-evaluation.json)、[机器可读统计](comparison.json)、[全部Top10失败及解释](检索结果与失败记录.md)。例如R34正确表格在E5第8名而top5漏；R03已出现正确文档但标注anchor未在候选中，说明“文档命中”与“标注证据命中”有差别，也提醒anchor不穷尽等价语义。N03不存在指定型号资料仍返回候选，不能把相近片段当作适用答案。

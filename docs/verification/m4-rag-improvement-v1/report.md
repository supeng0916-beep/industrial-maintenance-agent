## 偏差与解释限制

1. **非盲改写**：改写者（本Agent）在写改写前已读交接文档、失败记录（含失败题→目标文档/页映射）、集成复核与R17/R29/R34探针报告，存在选择偏差；完整披露见改写文件 `bias_disclosure` 字段。
2. R17 仅达第10名，@5问题未解决；R34类表格题对"改写用词是否恰好贴近表格行"敏感。
3. 24题小样本；人工改写是诊断探针，**不是可自动部署的查询翻译器**。若D2选择自动改写，需先完成模型运行方式决策（D4）并测超时/回退/原意保留。
4. 命中是文档/页/anchor证据匹配，不是回答正确率；距离不是置信度。
5. 原10道holdout已被历史工作观察，本实验未使用，也未将其当盲测。
